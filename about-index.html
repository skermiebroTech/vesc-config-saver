About

VESC Config Saver backs up and explains the settings on VESC-based balance boards (DIY Onewheel-style builds). It reads the motor config, app config and package configs such as Refloat, Float and TNT, from the controller and from every other VESC device on the board's CAN bus, like a VESC Express. It works with every VESC firmware release from 3.55 to 7.01.

What does VESC Config Saver do?

It connects to a VESC-based board over Bluetooth, reads the motor config, app config and every package config (Refloat, Float, TNT, Balance and others) from every VESC device on the board's CAN bus, and opens them in a config viewer. There you can download everything as one JSON file.

Can it change the settings on my board?

No. The config saver only sends read commands: firmware version, CAN scan, read motor config, read app config and read package config. The commands that write settings are not in the code. The ride logger also only reads, with one side effect: downloading Refloat's on-board recording pauses that recording, the same as Refloat's own screen does, and it restarts next time you engage. The source is on GitHub if you want to check.

Which boards and controllers does it work with?

Any VESC controller reachable over Bluetooth, either through a VESC Express (for example JetFleet F6, Thor 300/301/400, Tronic X12, or kits with an added Express) or through an NRF Bluetooth module. It has been tested on a JetFleet F6 with a VESC Express.

Which firmware versions are supported?

Every VESC firmware release from 3.55 to 7.01, including the built-in Balance app in firmware 3.62 to 6.02. Package settings are readable on any version because the controller sends their definitions.

Which packages are supported?

Refloat, Float, TNT (Trick and Trail), the Balance package and any other package that registers a config page, on any device on the CAN bus. VESC Express settings are read too.

Does it save my Wi-Fi password or Bluetooth PIN?

No. Passwords and PINs, such as a VESC Express's Wi-Fi password and Bluetooth PIN, are replaced with "(hidden)" and never saved.

Which browsers work?

Chrome on Android, and other Chromium browsers such as Edge, Opera and Samsung Internet. Firefox and iPhone Safari do not support Web Bluetooth. The config viewer works in any browser.

What does the config viewer show?

A card for every setting with its value, a plain-language explanation for beginners, a practical tip, and whether it was changed from the default. It has search, a filter for changed settings, and a desktop layout.

Can it log ride data like a blackbox?

Yes. The ride logger records live data over Bluetooth at about 10 to 30 samples a second (speed, duty, currents, voltage, temperatures, pitch, roll, setpoints and foot sensors with Refloat), or downloads Refloat's on-board data recording, which captures a few seconds at the full balance-loop rate and needs firmware with data recording (Refloat Extras). Both show synced charts with disengage, pushback and wheel slip events, and export to CSV.

Can I compare two configs?

Yes. The compare page opens two saved configs, or one config against the default values, and lists every setting that differs with both values, how much it changed, and what the setting means. You can download the differences as CSV.
