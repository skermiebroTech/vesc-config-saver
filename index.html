VESC Config Saver

Reads the motor, app and package settings (Refloat, Float, TNT and others) from every VESC device on your board over Bluetooth, then opens them in the config viewer, where you can download them as one file. Already have a file? Open the config viewer.

  • Connect to controller
  • Read firmware version
  • Read motor config
  • Read app config
  • Read packages (Refloat, Float, TNT and others)
  • Open config viewer
